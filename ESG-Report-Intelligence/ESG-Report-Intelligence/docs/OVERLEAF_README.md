# Documentation (LaTeX / Overleaf)

1. In Overleaf: **New Project → Upload Project** and upload a zip of this `docs` folder
   (or create a blank project and upload `main.tex` plus the `figures/` folder).
2. Compiler: pdfLaTeX (Overleaf default). `main.pdf` is the already-compiled version.
3. Fill in your course details at the top of `main.tex` (`\coursename`, `\lecturer`, `\githuburl`).
4. Screenshots: the document already contains three real screenshots. Two more are shown as
   placeholder boxes until you add them – after analysing a report with your Gemini key, save
   - `figures/ui_metrics.png`  (ESG Metrics tab)
   - `figures/ui_evidence.png` (Evidence tab)
   and upload them to `figures/` in Overleaf. They appear automatically.
5. Experiment results: run the Prompt Lab in the app, click **⬇️ prompt_lab_results.tex**, and upload the
   file to `results/` in Overleaf. Section 13.3 includes it automatically. Then write the short
   discussion paragraph below it.
